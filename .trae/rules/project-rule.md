pytauri概述:
pytauri 是通过 Pyo3 实现的 Python 的 Tauri 绑定。支持 Tauri 官方插件。
pytauri 实现了与 tauri 相同的 IPC API。你可以通过 pytauri.Commands 使用它。
项目的 commands 均在 `src-tauri/src-python/instatune/commands.py` 下进行注册。当运行 npm tauri dev 后，与commands 绑定的TypeScript 客户端代码将会在 `src/client` 目录中生成。


pytauri Commands 绑定生成的客户端代码示例：
<示例>
```python
class Person(_BaseModel):
    """A simple model representing a person.

    @property name - The name of the person.
    """

    # 👆 This pydoc will be converted to tsdoc
    name: str


# ⭐ Just use `commands` as usual
@commands.command()
async def greet_to_person(body: Person) -> str:
    """A simple command that returns a greeting message.

    @param body - The person to greet.
    """
    # 👆 This pydoc will be converted to tsdoc
    return f"Hello, {body.name}!"

```

项目使用异步 async 方式调用所有的 command 函数
如果在项目中使用到了同步阻塞函数，需要通过 `async_tools.to_async` 装饰器将其转换为异步函数。
例如：
```python
from time import sleep
from typing import Annotated

from pytauri import Commands, State
from pytauri_utils.async_tools import AsyncTools

commands = Commands()


@commands.command()
async def command_handler(async_tools: Annotated[AsyncTools, State()]) -> None:
    # ⭐ Convert a synchronous blocking function to an asynchronous one
    @async_tools.to_async
    def some_blocking_task(secs: int) -> None:
        print("Running a blocking task...")
        sleep(secs)

    # ⭐ Run blocking task in a separate worker thread
    await some_blocking_task(1)
    # async_tools.to_async 也可以直接调用
    # await async_tools.to_async(some_blocking_task)(1)
    # 如果需要在同步函数中调用异步函数，使用 async_tools.to_sync
    # 如果需要在后台执行任务, 可以使用 async_tools.task_group.start_soon(task_func,params...)

```

async_tools 可以从状态中获取:
```python
from pytauri import (
    Manager,
    AppHandle
)
from pytauri_utils.async_tools import AsyncTools

# app_handle: AppHandle
async_tools = Manager.state(app_handle, AsyncTools)
```

Global Events  全局事件
要在python中触发全局事件，可以使用 `Emitter.emit` 方法。

```
class Payload(BaseModel):  # or `RootModel`
    url: str
    num: int


def emit(app_handle: AppHandle) -> None:
    # emit(slf: ImplEmitter, event: str, payload: BaseModel) -> None
    # 前端使用 import { listen } from '@tauri-apps/api/event';
    Emitter.emit(
        app_handle, "event_name", Payload(url="https://example.com", num=42)
    )

```

Channels 通道
通道旨在快速传递有序数据。它们在内部用于流式操作，例如下载进度、子进程输出和 WebSocket 消息。
要使用 channel，只需将 JavaScriptChannelId 字段添加到 BaseModel/RootModel，然后使用 JavaScriptChannelId.channel_on 获取一个 Channel 实例即可。
使用示例:
```python
from pytauri import Commands
from pydantic import RootModel
from pytauri.ipc import Channel, JavaScriptChannelId
from pytauri.webview import WebviewWindow

commands = Commands()

Msg = RootModel[str]


@commands.command()
async def command(
    body: JavaScriptChannelId[Msg], webview_window: WebviewWindow
) -> None:
    channel: Channel[Msg] = body.channel_on(webview_window.as_ref_webview())

    # 👇 you should do this as background task, here just keep it simple as a example
    channel.send_model(Msg("message"))

```
```js
const channel = new Channel<string>((msg) => console.log(msg));

await pyInvoke("command", channel);
```

项目中对异常进行捕获并使用日志记录时，需要同步记录异常信息(包含错误的文件与行号)。
例如：
```python
import logging

logger = logging.getLogger(__name__)

try:
    # 一些可能会抛出异常的代码
    result = some_function()
except Exception as e:
    logger.error(f"发生异常: {e}", exc_info=True)
```
